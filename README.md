# 📊 Análise de Vagas na Área de Dados (LinkedIn - Abril/2025)

> Explorando o mercado global de trabalho em dados usando Python e visualizações interativas.

---

## 📁 Sobre o Projeto

Este projeto tem como objetivo analisar um conjunto de dados com **vagas da área de dados** extraídas do LinkedIn (via Kaggle), com foco em cargos como:

- **Data Analyst**
- **Data Engineer**
- **Data Scientist**
- **BI Analyst**
- **ML Engineer**

A análise abrange vagas publicadas em **abril de 2025** e busca identificar as principais tecnologias exigidas, empresas contratantes, países mais ativos e a evolução temporal das oportunidades.

---

## 📊 Ferramentas Utilizadas

- **Python**: manipulação de dados com `pandas`, visualizações com `seaborn`, `matplotlib` e `plotly`
- **Google Colab**: execução e documentação do notebook
- **Power BI** (fora do notebook): visualização e modelagem adicional (não incluído neste repositório)

---

## 🔧 Etapas Realizadas

1. Upload e leitura do dataset (CSV)
2. Padronização e limpeza dos dados
3. Conversão de datas e extração de mês/ano
4. Criação de colunas personalizadas:
   - País (`country`)
   - Categoria do cargo (`job_category`)
   - Contagem de palavras na descrição
5. Análise e visualizações:
   - Distribuição por cargo
   - Distribuição por país
   - Evolução temporal de vagas
   - Principais empresas contratantes
   - Skills técnicas mais citadas

---

## 📌 Principais Insights

- O cargo **Data Analyst** foi o mais comum entre as vagas.
- O **Brasil** representa uma parte significativa das oportunidades, mas há presença global.
- As empresas com mais vagas são grandes players do mercado tech.
- As *skills* mais exigidas foram: `Python`, `SQL`, `Excel`, `Power BI`, `AWS`, entre outras.
